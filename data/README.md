# Local data area

This directory is intentionally excluded from Git except for placeholders and this README.

Copy only the official challenge files into `train/` and `test/` using the names listed in the
root README. Do not edit the raw files. The audit command records SHA-256 fingerprints so every
experiment can be traced to the exact bytes used.

No sample rows have been invented here: synthetic records used by unit tests live only in test
fixtures created in memory.
